# SQLify

**SQLify** es una aplicación que te permite hacer **preguntas en lenguaje natural** sobre una base de datos tipo Spotify y obtener:

- La **consulta SQL** generada por un modelo de lenguaje (Gemini).
- Los **resultados** ejecutados contra una base MySQL/MariaDB.

El proyecto está dividido en dos partes:

- [backend/](backend/README.md) → API en Node/Express + MySQL + Gemini.
- [frontend/](frontend/README.md) → SPA en React + Vite que consume esa API.
